# Capture notes

Raw notes from driving Kyle's mirrored iPhone to read game data off the screen.
These are the working record, not the knowledge base — facts only reach the bot
once they are written into `src/features/ai/seed-facts.ts`.

Kept in the repo because the captures are long, span sessions, and are easy to
get subtly wrong. The notes record what was seen AND the reading mistakes made
along the way, so the same traps are not re-entered.

- `treasures-runes.md` — the Treasure system, which is what this game calls
  runes. Members ask about it constantly and the bot has no data yet.
