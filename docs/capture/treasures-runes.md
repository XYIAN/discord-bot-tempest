# Treasure (rune) capture — Wittle Defender

Working notes from driving Kyle's mirrored iPhone. Written as we go so the
session is resumable; the roster is large and will not fit one context.

In this game the rune system is called **Treasure**. Kyle: "the treasure screen
which is all runes."

## System rules (verbatim, from the Treasure ⓘ panel)

1. Players can carry up to 12 treasures into battle. Initially, only 1 can be
   carried, but more slots unlock as the player levels up.
2. Only one of each treasure can be carried.
3. After obtaining a treasure, it can be fused into a higher rarity.
4. Improving a treasure's rarity enhances its stats and unlocks new skills.
5. All deployed heroes benefit from the treasure's stats.
6. Once a treasure reaches Epic rarity, a treasure reset feature is unlocked,
   allowing players to reclaim materials used in crafting.

Verified complete — the panel does not scroll.

## Rarity ladder

Six skill tiers, one per rarity, colour-coded in this order:

🟢 → 🔵 → 🟣 → 🟠 → 🔴 → ⚪

Frostone Edge is **Legendary +1** and had exactly the first four unlocked in the
aggregate panel, which puts 🟠 = Legendary. Six tiers matches the hero rarity
ladder (Common, Rare, Epic, Legendary, Mythic, Sublime) exactly, and system rule
6 mentions Epic as a threshold — consistent with 🟣 = Epic. **Not yet confirmed
on screen; verify against a treasure at a different rarity or the Fuse screen
before writing this as a fact.**

Rarity carries a **+N** suffix ("Legendary +1"), same shape as the hero star
tiers.

## How the inventory grid really works — READ THIS BEFORE CAPTURING

The grid is NOT a list of distinct treasures. It holds **multiple copies of the
same treasure at different rarities** — Frigid Coronet appears both as a carried
high-rarity copy and as this Uncommon one. The carried copy's button says
**Remove**; a spare copy's says **Replace**.

Consequences for the capture:

1. **Only distinct NAMES need capturing.** The ~150 grid entries collapse to far
   fewer treasures. Capture by name and skip any name already recorded.
2. **A detail page shows the full six-tier ladder regardless of that copy's
   rarity.** This Uncommon copy lists all six, including the 🔴 and ⚪ tiers it
   has not earned. So a low-rarity copy is just as good a source — no need to
   hunt for the highest copy.
3. **Detail modals scroll.** This one was cut off mid-sentence at "1.5% of Frost
   Lich's…" and the last two tiers were below the fold. Scroll every one.

## The structural pattern (from Kyle, confirmed against captures)

Kyle: "generally two runes per hero, one for attack pushing and one for defense,
and then each element has a main element rune like to boost all wind."

Confirmed against every treasure captured so far — four heroes, four for four:

| hero | attack rune (ATK%) | defense rune (HP%) |
|---|---|---|
| Polar Captain | Frostone Edge | Frigid Hexblood |
| Frost Lich | Perpetual Blizzard | Frigid Coronet |
| Fabled Lyra | Aeolian Core | Windlock Casket |
| Monkey King (Sun Wukong) | Phoenix Gilded Crown | *not carried — expect one to exist* |

Element rune: **Soulfrost Gyro** = Ice DMG, no hero portrait, boosts the whole
element.

This is the organising principle for the whole system and it makes the capture
predictable: for each hero expect an ATK rune and an HP rune, and for each
element expect one element-wide rune. It also gives a completeness check — a
hero with only one rune recorded means the other has not been found yet, not
that it does not exist.

captured is "not in Kyle's collection", never "does not exist in the game".
Facts written from this must say so.

## Filter categories

The **All** dropdown filters by element: **Ice, Fire, Electro, Wind,
Xenoscape** — the same five as heroes, and it spells it **Electro**, matching
the existing `element-naming-variants` fact.

Capturing element by element is the sane order, and gives usable output after
each pass rather than only at the end.
